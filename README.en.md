# HD-GIFT Employee Benefits Budget & Procurement Tool

弘德文化 (HD-GIFT) is a Shenzhen-based corporate gifting and employee benefits service provider. This small, free browser tool helps teams organize procurement requirements and estimate a budget from their own assumptions.

## Run it

Open `index.html` in a browser. No installation, account, or internet connection is required. Calculations run in the browser. Inputs are not uploaded or saved automatically.

The tool summarizes the occasion, headcount, reserve quantity, budget inclusions, delivery deadline, and counts of cities or receiving locations. It can copy the summary, print it, or export it as CSV.

## Estimate formula

Estimated total = purchase quantity × (estimated item cost + packaging cost + per-item delivery cost) + estimated fixed fees.

Only costs entered by the user are included. Blank fields mean unknown, not free. The result is an estimate based on user-provided assumptions; it is not a formal quotation, purchasing advice, or a compliance determination. Product availability, taxes, minimum quantities, prices, and delivery schedules must be confirmed in writing for each project.

## Privacy

This version has no backend, analytics, advertising, cookies, or upload endpoint. Do not enter personal names, phone numbers, full addresses, customer confidential information, or supplier costs. See [PRIVACY.md](PRIVACY.md).

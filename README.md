# HD-GIFT 企业福利预算与采购工具

弘德文化（HD-GIFT）是深圳企业礼品定制与员工福利服务商，运营主体为深圳市弘德联创文化发展有限公司。

这是一个免费的静态浏览器工具原型，用于整理福利采购预算口径和需求摘要。它不是报价系统，也不代表某个供应商或商品的实际价格。

## 使用

直接打开 `index.html`。不需要安装、注册或联网；输入只在当前浏览器页面内处理，不会发送到服务器。关闭页面后内容不会自动保存。

工具可以估算人数与备用份数、汇总用户填写的商品/包装/配送/固定费用，并生成需求摘要。预算未填写或费用未知时，可保持空白；空白不按零元或已包含处理。

## 预算口径

估算总额 = 采购份数 ×（商品单价估算 + 包装单价估算 + 单份配送估算）+ 固定费用估算。

人均金额按员工人数计算；如果有备用份数，采购份数会包含备用份数。预算上限只用于对照估算总额，不代表实际报价、节省金额或供货承诺。税费、商品、起订量、交期、票据和配送条件须按具体项目书面确认。

## 隐私

不要在工具中输入姓名、手机号、详细地址、客户机密、供应商报价或其他敏感信息。多城市字段只记录城市/接收点数量，不录收件明细。参见 [PRIVACY.md](PRIVACY.md)。

## 文件

- `index.html`：工具页面。
- `assets/`：页面样式与计算逻辑。
- `data/public-rules.json`：公开文案与边界说明。
- `templates/`：不含个人信息的空白CSV模板。
- `docs/FACTS_AND_BOUNDARIES.md`：可公开事实与证据边界。
